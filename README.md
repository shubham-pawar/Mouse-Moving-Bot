# Mouse Moving Bot

A lightweight Python utility that automatically moves your mouse cursor every 2 seconds to prevent screen lock and keep your computer awake during long sessions.

## ✨ Features
- Automatically moves the mouse every 2 seconds
- Minimal CPU usage
- Simple one-click start/stop

## 🚀 Quick Start

1. **Clone the repository:**
   ```bash
   git clone https://github.com/shubham-pawar/Mouse-Moving-Bot.git
   ```

2. **Install requirements:**
   ```bash
   pip install pyautogui
   ```

3. **Run the bot:**
   ```bash
   python mouse_bot.py
   ```

## 💡 How It Works
- Moves the mouse cursor slightly every 2 seconds
- Prevents screensaver and screen lock
- Runs silently in the background
- Press `Ctrl+C` to stop

## 🛠 Requirements
- Python 3.6+
- `pyautogui` library

## ⚠️ Important Notes
- First run may ask for accessibility permissions
- Small, random movements to avoid detection
- Safe for personal use during work/study sessions
